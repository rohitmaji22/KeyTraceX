capabilities

Built for Security
Designed for Ethics

⌨️

01

Real-Time Capture

Captures every keystroke in real-time with precise timestamps. Lightweight engine designed for minimal performance impact on the host system.

🔒

02

AES-256 Encryption

All captured data is immediately encrypted using industry-standard AES-256. No plaintext is ever written to disk — encryption happens in memory.

🔑

03

Session-Based Keys

Encryption keys are generated per session and never persisted to storage. Once a session ends, the key is gone — ensuring forward secrecy.

⏳

04

Auto Log Deletion

Logs are automatically purged after a configurable retention window. Privacy-first design ensures data doesn't accumulate unnecessarily.

📄

05

Report Generation

Generate structured activity reports from encrypted logs. Human-readable summaries for authorized review without exposing raw keystream data.

⚡

06

Lightweight Design

Pure Python implementation with minimal dependencies. Runs efficiently in the background with a tiny memory and CPU footprint.

security architecture

How KeyTraceX
Protects Your Data

01

Keystroke Capture

Event listener hooks into the OS keyboard input layer. Captures keystrokes with microsecond-precision timestamps.

02

Timestamp & Buffer

Each event is annotated with a monotonic timestamp and buffered in-memory before any disk operation.

03

AES-256 Encryption

Buffer contents are encrypted using the session key via the cryptography library. CBC mode with random IV per write.

04

Secure Storage

Ciphertext is written to the logs directory. File permissions are set to restrict unauthorized read access.

05

Auto-Delete & Report

Retention policy triggers automatic deletion. Reports are generated from decrypted data and then re-secured.

# Security Configuration ENCRYPTION_ALGO = "AES-256-CBC" KEY_PERSISTENCE = False PLAINTEXT_DISK = Never IV_STRATEGY = "random_per_write" # Session Lifecycle session_key = generate_key() on_exit = destroy_key(session_key) # Retention Policy AUTO_DELETE = True RETAIN_HOURS = 24 # File Permissions LOG_CHMOD = 0o600 # Ethical Gate AUTH_REQUIRED = True UNAUTH_USE = ILLEGAL

getting started

Up and Running
in Minutes

Clone the Repository

Download KeyTraceX from GitHub onto your Linux machine using git.

Enter the Directory

Navigate into the cloned project folder to begin setup.

Install Dependencies

Use pip to install the required Python packages from requirements.txt. Primarily the cryptography and pynput packages.

Run the Keylogger

Start the monitoring session. Ensure you have authorization before running on any system.

Codebase

KeyTraceX/ ├── src/ │ ├── keylogger.py │ ├── encryption.py │ └── report.py ├── logs/ │ └── [encrypted .log files] ├── reports/ │ └── session_report.txt ├── screenshots/ ├── .gitignore ├── banner.png ├── README.md └── requirements.txt

Modular & Readable Architecture

KeyTraceX follows a clean separation of concerns — each Python module handles one specific responsibility. The keylogger captures, the encryption module secures, and the report module analyzes.

Logs and reports are kept separate from source code, and all sensitive data directories are excluded via .gitignore to prevent accidental exposure.
